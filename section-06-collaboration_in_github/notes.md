## How to add collaborators in github?

For adding a collaborator into an private repository just go to settings then in Access go to collaborators and simplyy add peoples.

## How to protect a branch?

For protecting a branch go to settings in github then in Branches click Add classic branch protection rule then add name of branch and select options for rule.

## Requiring Reviews in Pull Requests

A Pull Request can be configured to require one or more approvals before merging.

A review can be used to find out what changes were made.

## Working with issues

An issue can be assigned to a person and given labels.

When you mention an Issue number using # in a commit message, GitHub automatically links that commit to the issue.

Example:
git commit -m "Fixed login bug #2"

Here, #2 refers to Issue #2.
