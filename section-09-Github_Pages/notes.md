## GitHub Pages Usage Restrictions

GitHub Pages is not intended for or allowed to be used as a free web hosting service to run your online business, e-commerce site, or any other website that is primarily directed at either facilitating commercial transactions or providing commercial SaaS.

## Intro to github pages

GitHub Pages is a static website hosting service provided by GitHub. It allows you to publish websites directly from a GitHub repository. It is simple way to showcase the product.

Just make sure that they are inside either of these three options.

1. master branch
2. gh-pages branch
3. docs folder inside your master branch

In GitHub Pages, Jekyll can:
- Convert Markdown files into HTML pages.
- Apply themes and layouts to your content.
- Generate blog posts and pages automatically.
- Create a complete static website from a GitHub repository.
